# Changelog

## 2.1.0 — Mises à jour vivantes & notifications

- ajout du centre « Mises à jour & notifications » ;
- ajout d’un catalogue de cours distant basé sur `content/manifest.json` ;
- téléchargement et lecture hors connexion des nouveaux cours ;
- ajout de trois cours initiaux : GCP, décision météo et rapport final ;
- vérification périodique Android avec WorkManager ;
- notifications locales pour les nouveautés, installations et rappels ;
- demande automatique de permission sur Android 13 et versions ultérieures ;
- ajout du workflow de validation des contenus JSON ;
- exclusion de `content/` des compilations APK inutiles ;
- fonctionnement sans compte, Firebase ou base de données distante.

## 2.0.0 — DroneAtlas Academy

- transformation du catalogue initial en académie photogrammétrique ;
- ajout de 8 modules et 24 leçons ;
- ajout de six domaines d’application ;
- ajout des simulateurs de plan de vol, caméra, fragments et traitement ;
- ajout de trois missions évaluées ;
- ajout du quiz, du glossaire, des badges et des XP ;
- ajout du rédacteur de rapport ;
- ajout de l’assistant DroneAtlas hors ligne ;
- refonte responsive sombre/clair ;
- automatisation Android et GitHub Pages.
